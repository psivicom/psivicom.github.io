Use this as the expanded `SECURITY.md`:

```md
# Security Policy — psivicom.github.io

## Purpose
This policy describes how security issues, authorship, traceability, and project integrity are handled for psivicom.github.io.

## Scope
This policy applies to the main branch and to all linked project files, notebooks, drafts, references, and archived artifacts.

## Licensing
- Code fixes and technical patches: Apache-2.0
- Policy text and documentation: CC-BY-4.0
- This repository follows a dual-license model where file-level licensing is explicit.

## Reporting Security Issues
Report security concerns through the psivi.com contact form.

Do not submit sensitive details in public issues or public comments.

Security reports are kept private until a fix is prepared and released.

## Handling of Reports
- Triage reports privately
- Preserve a dated log of findings and actions
- Link each report to relevant source files and notebooks
- Keep reference files at the bottom of the project for traceability
- Avoid orphan files; every security-related file must be linked from this policy or an index file

## Authorship and Attribution
- Use dated notebooks and drafts
- Keep source files grouped with their related analysis
- Preserve provenance for major changes
- Use Zenodo for archival copies and stable identifiers when appropriate
- Separate working drafts from final releases

## Secure Project Practices
- Maintain backups of original files and metadata
- Keep changelogs for material changes
- Review linked files for completeness before release
- Do not overwrite source material without preserving prior versions
- Store supporting references in dedicated folders rather than scattered files

## Release Process
- Prepare fixes in a separate branch or draft area
- Verify linked files and references before publishing
- Publish only after reviewing traceability and attribution
- Include release notes for significant changes

## Related Documents
- [Trust and Provenance](TRUST_AND_PROVENANCE.md)
- [Security Plan](SECURITY_PLAN.md)

## Contact
Use the psivi.com contact form for all security-related reports.
```
