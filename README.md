## License (FAIR R1.1) — NASA SPD-41a Compliant

This repository contains both software and open science content, licensed separately per NASA TOPS / SPD-41a guidance:

| Type | Scope | License | File |
|------|-------|---------|------|
| **Code** | `/src`, scripts, notebooks, `*.py`, `*.js` | Apache-2.0 | [LICENSE](LICENSE) and [LICENSES/Apache-2.0.txt](LICENSES/Apache-2.0.txt) |
| **Content** | README, docs, OSDMP, figures, data, text in `/docs` | CC-BY-4.0 | [LICENSES/CC-BY-4.0.txt](LICENSES/CC-BY-4.0.txt) |

- **SPDX for code:** `Apache-2.0`
- **SPDX for content:** `CC-BY-4.0`

This split satisfies FAIR R1.1 (clear, accessible license) and NASA SPD-41a: data under CC-BY, software under Apache-2.0.

Why Apache-2.0: Includes explicit patent grant, required for NASA gold-standard, fully compatible with MIT/BSD.
