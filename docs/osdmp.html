How to keep md and html in sync (fix for your issue)

You had /docs/osdmp.md but /docs/osdmp.html was missing, so psivi.com/docs/osdmp.html 404s.

Solution 1 — quick fix (what I just did): commit this file as docs/osdmp.html. Done.

Solution 2 — automated (recommended): add a GitHub Action to build html from md on every push:

# .github/workflows/docs.yml
name: build-docs
on:
  push:
    paths: ['docs/*.md']
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pandoc/actions/setup@v1
      - run: |
          pandoc docs/osdmp.md -s --metadata title="OSDMP" -c ../style.css -o docs/osdmp.html
          # inject SPDX header if needed
      - uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "docs: auto-build osdmp.html from md"
          file_pattern: docs/osdmp.html

Or switch to Jekyll: add front-matter to osdmp.md and enable Pages → Jekyll will auto-render /docs/osdmp.html.
