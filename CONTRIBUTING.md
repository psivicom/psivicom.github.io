# Contributing

## How to Contribute - NASA TOPS / FAIR

We welcome contributions that follow FAIR principles.

### License Agreement
By contributing, you agree that:
- Code contributions are licensed under Apache-2.0
- Documentation/data contributions are licensed under CC-BY-4.0

### Process
1. Fork the repo
2. Create a branch
3. Ensure files have SPDX identifier:
   - Code: `// SPDX-License-Identifier: Apache-2.0`
   - Content: `SPDX-License-Identifier: CC-BY-4.0`
4. Submit PR with clear description

### FAIR Requirements
- Add citation metadata if adding datasets
- Update CITATION.cff if needed
- Provide DOI for new data via Zenodo

Questions: https://psivi.com
