# Contributor Covenant Code of Conduct — psivicom.github.io — Excellence

We follow NASA TOPS Open Science ethos: inclusive, transparent, reproducible.

- Be respectful, welcoming, collaborative
- No harassment, no discrimination
- Prioritize open science integrity, FAIR, dual license compliance (Apache-2.0 for code, CC-BY-4.0 for data/media)
- Cite, give attribution

Enforcement: Louis-Philippe Audette — via https://psivi.com contact.

References: Contributor Covenant v2.1, NASA TOPS Code of Conduct, UNESCO Open Science Recommendation.
