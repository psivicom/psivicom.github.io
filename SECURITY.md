## Reporting a Vulnerability
For EU CRA / Horizon Europe Art. 17 compliance:

- **Do not** open a public issue for security vulnerabilities.
- Email: security@psivi.com (or open a private GitHub Security Advisory)
- We will acknowledge within 72h per EU CRA requirements.
- No personal data is processed by this site (GDPR Art.5 compliant - no data collection).
