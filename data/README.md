## 4. Data Standards & Provenance

To ensure strict alignment with NASA SPD-41a and ESA Open Science mandates, all data in this folder adheres to the following rules:

- **Open Formats:** Data is stored in non-proprietary, machine-readable formats (e.g., .csv, .json).
- **Rich Metadata:** Every dataset is accompanied by a metadata.json or datapackage.json file detailing the methodology, spatial extent, and temporal coverage.
- **Zulu Timestamps:** All temporal data, logs, and "Last Updated" frontmatter strictly use RFC3339 UTC with millisecond precision (e.g., `2026-09-11T00:00:00.000Z`).
- **Traceability:** The provenance of all derived data (e.g., SAR-optical fusion outputs) is explicitly linked back to the raw source inputs and the processing scripts used.
