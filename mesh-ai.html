1. The Observer (Forage Agent)

Biological Parallel: Sensory neurons

Collects environmental telemetry (temperature, humidity, bloom data) from the Goldstream Watershed. Encodes observations into 4096-dimensional vectors and seals them as .psvc containers. Runs every 12 hours.

2. The Dopamine Signal (Critic Agent)

Biological Parallel: Reward prediction error

Compares yesterday's prediction against actual weather data. Calculates drift and writes correction vectors. This is how the mesh learns from mistakes—exactly like dopamine signaling in biological learning.

3. The Immune System (Governor Agent)

Biological Parallel: Immune surveillance

Enforces Pico VRAM limits, monitors memory usage, and strictly prohibits plaintext passing between agents. Ensures the mesh stays lightweight and secure.

4. The Neocortex (Cortex Agent)

Biological Parallel: Memory consolidation during sleep

Performs K-Means clustering to identify distinct ecological states (Bloom, Drought, Normal). Prunes redundant vectors (>95% similarity) while preserving novel, high-entropy events. Runs every 6 hours.

5. The Scholar (Literature Agent)

Biological Parallel: Contextual memory

Ingests peer-reviewed pollinator ecology papers via free APIs (PubMed, Crossref). Encodes scientific knowledge as vectors, allowing the mesh to ground local observations in global research.

6. The Publisher (Zenodo Agent)

Biological Parallel: Scientific communication

Automatically deposits consolidated ecological states to Zenodo with permanent DOIs. Makes the mesh's discoveries citable in academic literature.

03 — .psvc Containers: The Atomic Unit of Intelligence

Every piece of knowledge in the mesh—every observation, every scientific paper, every learned pattern—is stored as a .psvc (Pico Service Container) file. These are not traditional files. They are sealed, compressed, cryptographically signed vessels of mathematical truth.

.psvc Binary Specification
┌─────────────────────────────────────────────────────────┐
│ .psvc Container Structure (14-byte header + payload)    │
├─────────────────────────────────────────────────────────┤
│ Bytes 0-3   : Magic Signature ('PSVI')                  │
│ Byte  4     : Protocol Version (v1)                     │
│ Byte  5     : Precision (0=INT8, 1=Float16, 2=Float32)  │
│ Bytes 6-9   : Vector Dimensions (e.g., 4096)            │
│ Bytes 10-13 : Compressed Payload Size (uint32)          │
│ Bytes 14+   : zlib Level-9 Compressed Vector Data       │
└─────────────────────────────────────────────────────────┘

Why This Matters

A typical ecological observation stored as JSON might be 2-4 KB. The same observation as a .psvc container is 200-400 bytes—a 10x compression ratio. This allows thousands of vectors to fit in the memory footprint of a single traditional database record.

Cryptographic Integrity

Each container is hashed with SHA-256. Any modification breaks the hash, ensuring absolute data integrity from the moment of creation through volunteer processing to final publication.

The Pico Limit: The Governor Agent enforces a strict rule: no more than 5 containers may be loaded into active VRAM simultaneously. This forces the mesh to be selective, efficient, and focused—just like a biological brain that can only hold a few thoughts in working memory at once.

04 — Neuroplasticity: How the Mesh Learns

Traditional AI models are static. Once trained, they don't learn. The Mesh Pico AI is continuously neuroplastic—it strengthens useful patterns, prunes redundant noise, and consolidates long-term memory, exactly like a biological brain.

Synaptic Strengthening (K-Means Clustering)

Every 6 hours, the Cortex Agent wakes up and performs K-Means clustering on all raw vectors. It groups similar observations into distinct "Ecological States":

  • State 0: Early Bloom (warm, dry, high forage)
  • State 1: Peak Season (optimal conditions)
  • State 2: Drought Stress (hot, dry, limited forage)

These master vectors are permanent. They represent the watershed's core ecological patterns.

Synaptic Pruning (Entropy-Based Deletion)

After clustering, the Cortex calculates cosine similarity between each raw vector and the master states. If a vector is >95% similar to a master state, it is mathematically redundant and gets pruned.

Why this is brilliant: The mesh doesn't delete data based on age. It deletes data based on information content. Novel, unusual events (freak storms, unexpected blooms) are preserved forever. Routine, predictable days are pruned to save space.

05 — The Volunteer Mesh: Git as the Global Memory Bus

Decentralized Compute
No Cloud. No APIs. Just Git.
The Mesh Pico AI uses Git repositories as distributed RAM. When a volunteer joins the mesh, they clone the repository, open sealed .psvc containers in their local VRAM, perform mathematical consensus, and push results back.

This is not a metaphor. Git literally functions as the memory bus—git pull loads state, git push writes results. The mesh scales infinitely because every volunteer adds storage and compute capacity.

How a Volunteer Joins

  1. Clone the repository: git clone psivicom/psivicom.github.io
  2. Run the volunteer daemon: python volunteer_node.py
  3. The daemon pulls sealed containers, opens them in local VRAM, computes consensus, and pushes results
  4. Open a PR to merge contributions back to the main mesh

Privacy & Security

  • Sandboxed execution: Volunteers process encrypted vector fragments, not raw personal data
  • Zero persistent storage: Containers are deleted after processing
  • Cryptographic verification: Every result is hashed and verified before merging
